# 用户手册

## 第一次打开

1. 欢迎页会介绍鲸鲸。点“开始”进入引导。
2. 填 DeepSeek API Key（可跳过，先体验离线演示）。
3. NapCat：没有安装可点“去安装”，或先跳过。
4. 选一个人设：鲸鲸是默认的 DeepSeek 蓝鲸娘；其余 7 位是鲸鲸的人格分支。
5. 填主人 QQ（用于权限和主动消息），选择是否开启自主生活。
6. 完成，进入首页。

## 首页

- Hero：鲸鲸的实时动画、心情与关系；可以“聊两句”“听她说”“让她创作”。
- 心情卡：mood、愉悦/精力/亲近，来自真实情绪状态。
- 成长卡：Lv、阶段、XP、连续天数。
- 正在发生：她刚做的事（聊天、日记、说说、B站、学习、反思、主动关心）。
- 她的小世界：最新日记、空间说说、B站发现、学习笔记。
- 功能引导：5 步完成核心设置。
- 创作工坊：文生图 / 视频 / 音乐，MiniMax + Suno。

## 聊天

- 左栏会话列表；中栏消息；右栏记忆与情绪洞察。
- 输入框 Enter 发送、Shift+Enter 换行；可发梗图。
- 没有 Key 时是离线演示回复（带来源标记）；配置后自动真实生成。
- 人设切换、清空/删除会话；群聊会显示发送者。
- QQ 收到的消息会实时出现在对应会话；鲸鲸的回复同步发回 QQ。

## 人设

- 8 张内置卡；点开查看完整档案：特点、口头禅、小动作、脾气、喜欢/讨厌、背景、语感、边界、示例、TTS。
- “切换”会立即生效；“编辑”可覆盖内置人设；“新建”以鲸鲸为模板；“AI 生成”让 DeepSeek 设计新人格（需要 Key）。
- 提示词预览可查看最终发给模型的完整 System Prompt。

## 记忆库

- 左侧按全局自我/私聊/群聊分组；群聊下可看群成员。
- 每份文档包含关系雷达、事实、时间线、承诺、锚点、情绪轨迹。
- 支持搜索、编辑手写备注、忘记单条事实、删除文档、打开记忆文件夹。
- 重要：每个联系人独立记忆，群聊只注入当前群+当前发言人，不会把 A 的记忆带给 B。

## 成长日记

- Hero：情绪仪表、成长阶段、特质、最近自省。
- Tabs：日记、QQ空间、B站发现、学习笔记、活动轨迹。
- “现在写日记”“生成说说”“刷一会儿 B 站”“现在学点什么”均可手动触发。
- 说说可保存草稿或自动发布到 QQ 空间（需要 NapCat 在线）。
- 发布设置（可见范围、时段、间隔）在设置页调整。

## 意识海

- 识海：每件经历过的事都是一个点；可搜索、按深度筛选，点击查看来源与详情。
- 原意识：她最深处的自我与锚点，永远不会被上下文压缩掉。
- 心光：此刻她在注意什么，未完成话题是什么。
- 心流：一个念头如何牵出下一个念头。
- 遗忘：细节随时间下沉，重要的反而更清晰；原文不会删除。
- “继续醒来”会生成上次聊到哪里的连续性 brief。

## 群聊开关与白名单

设置 → 权限 → 群聊模式：

- **仅白名单群（默认）**：只有群白名单里列出的群号可以聊天。
- **关闭全部群聊**：任何群都不回复。
- **全部群聊**：所有群都可以聊天（仍受 @/唤醒词、黑名单、敏感词限制）。

群白名单在同一个设置卡片里添加，可填群号。默认白名单为空，所以升级后不会自动在陌生群说话。

## 人设数据隔离与音色

- 每个人设拥有独立的长期记忆根目录：切换人设后，记忆库、日记、说说、学习、活动、成长、情绪与意识海只显示当前人设的数据，互不串场。
- 首次升级会把旧版全局记忆自动归到当前人设，不会丢失。
- 每个人设可绑定自己的 BreezeBlue 音色：切换人设时自动切换；在「设置 → 模型与语音 → 声音与音色」手动换音色，会绑定到当前人设，不会覆盖其他人设。
- 人设详情 → TTS 音色 可以查看当前绑定的音色。

## 一键清空非设置数据

设置 → 上下文与数据 → **一键清空**：

- 清除：会话、所有记忆、日记、说说、成长、情绪、意识海、表情包、媒体文件、费用账本。
- 保留：API 密钥、全部模型/参数设置、人设定义、每个人设绑定的音色、NapCat 安装与登录配置。
- 清理后应用自动重启，进入全新空白状态；不会再自动生成演示数据。

## 聊天里的命令与高成本工具

私聊和群里都可以直接发：

- `好感`、`好感度`、`你对我的好感度`、`对我的好感度`：读取发送者在当前会话里的关系档案，生成一张好感卡片图片。
- `画 一只蓝鲸在吃白饭`：调用 MiniMax 文生图并发送图片。
- `视频 蓝鲸跃出海面`：调用 MiniMax-H3 生成视频并发送。
- `唱首歌` / `唱《起风了》` / `唱一首 夜空中最亮的星`：调用 Suno 唱歌；不指定就随机唱一首。

高成本工具默认只允许主人/管理员/白名单使用，并限制每个发送者每天的次数：
画图 5 次、视频 2 次、唱歌 3 次，冷却 45 秒；在「设置 → 上下文与数据 → 聊天中的高成本工具」调整。
鲸鲸自主写日记、发说说、刷 B 站时不受这些聊天限制。

- **导入目录**：打开插件根目录，Agent 工具可直接写入插件清单。
- **插件市场**：预留入口，后期开放。
- 教程见 [插件制作教程](PLUGIN_AUTHORING.md)。

## 表情包库

- 内置 20+ 张鲸鱼娘表情包，聊天和说说里她会按当前心情自己挑一张。
- 支持上传自己的表情包、收藏、打标签、设置心情和停用/删除。
- 自主收集：每天最多 1–3 次，让她用 MiniMax 画一张新的鲸鱼娘表情；没有 MiniMax Key 时会只从已有内库挑选。
- 聊天自动发概率、说说自动配图概率、每日收集上限都在表情包库页面调整。

## 神经中枢

- 实时显示真实的思考阶段、DeepSeek token 流、记忆检索、工具调用和 QQ/语音/媒体组件活动。
- 粒子神经网由真实 neural:event 驱动；思考进程、数据流、发散网络、对话进度、组件状态、今日费用多个窗口。
- 可暂停实时流、清空视图、开启调试查看原始事件。

## 费用账本

- 记录真实 token 与调用量；费用按参考单价估算，可在预算与单价中调整。
- 查看本月/今日/全部、供应商分布、30 天趋势、最近调用明细、月预算。
- 清空记录只清账本，不影响真实调用或聊天；真实账单以服务商为准。

- 按类别展示 13 个内置插件；启用/禁用、配置、执行操作、健康检查。

- 新增功能以插件形式接入，详见 docs/PLUGINS.md。

## NapCat

- 状态、登录二维码、内嵌 WebUI、控制台、配置、诊断、安装引导。
- 所有操作都在本窗口；启动器由应用隐藏运行。
- 常用命令：登录信息 / 状态 / 帮助 / 重载配置 / 清屏。

## 设置

- API 密钥中心：5 个 Key 一个卡片，统一保存与测试。
- 模型与语音：端点、模型、音色同步/试听、语音概率。
- 权限：主人、管理员、白名单、群白名单、黑名单、陌生人策略、@ 规则。
- 自主生活：总开关、安静时段、日记/说说/B站/学习/反思的时段和间隔。
- 上下文与数据：预算、压缩阈值、保留窗口、记忆抽取开关、备份/重置。
- 外观：深色/浅色/跟随系统、5 种强调色、托盘行为、开机自启、内置素材库。
- 费用：预算与单价在费用账本页调整。

## 常见问题

- 没有反应/白屏：设置页查看日志目录；或重新启动。开发时确认没有 ELECTRON_RUN_AS_NODE=1。
- 对话报错：设置 → API 密钥中心测试 DeepSeek；检查余额/网络/代理。
- 不说 QQ：NapCat 页面确认 QQ 在线 + OneBot 已连接；群聊需要 @ 或唤醒词（设置可改）。
- 语音失败：BreezeBlue Key/音色、额度；QQ 语音还依赖 NapCat 的音频转换。
- 记忆混乱：确认没有手动编辑破坏 Markdown 数据块；可在记忆库删除重建。
- 想清空演示数据：设置 → 数据 → 清除演示会话；记忆可单独删除。
